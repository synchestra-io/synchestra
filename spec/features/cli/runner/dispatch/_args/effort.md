# --effort

Requests an adapter-specific effort value.

| Detail | Value |
|---|---|
| Type | String |
| Required | No |
| Default | Adapter or scheduler default |

## Supported by

`synchestra runner dispatch`

## Description

The value is passed unchanged and remains separate from the model selector.

## Examples

```bash
synchestra runner dispatch --prompt "Analyze architecture" --effort high
```
